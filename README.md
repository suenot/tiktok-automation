# tiktok-automation

This private project is for a Camoufox-based CLI that publishes a finished local video to a selected TikTok account. Calling services own their queues and schedules.

**Status:** design and repository setup. `tiktok-publish` is not implemented yet, and this repository cannot publish content. The [TikTok plan](https://gitlab.com/reforms-lab/root/-/blob/main/docs/publishing/tiktok.md) and [shared publishing contract](https://gitlab.com/reforms-lab/root/-/blob/main/docs/publishing/contract.md) define the first implementation and verification gates. A real post requires a selected account, video, caption, and explicit final-publication approval.

Version: see `VERSION`. Changes are recorded in `CHANGELOG.md`.
